# MayderC

Portafolio personal de MayderC. Next.js + next-intl (ES/EN).

## Desarrollo

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Deploy

En Vercel, el proyecto de MayderC debe tener **Root Directory = `mayderc`**. Este proyecto conserva sus variables de entorno actuales (sitio, email, MongoDB y admin).

El sitio de Danvrix vive en una carpeta y un proyecto aparte: `danvrix/`.
