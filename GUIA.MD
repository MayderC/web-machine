## Brand & Style
The system pairs neo-brutalist technical aesthetics with vintage engineering schematics. Designed for developers, systems architects, and creative technologists, it conveys rigorous competence, transparency, and retro-futuristic craft. 

The aesthetic is characterized by raw ink borders, warm archival canvas backgrounds (`#f7f6f0`), hard drop shadows with zero blur offset, and high-density monospaced typography balanced against crisp sans-serif headings. It eschews soft gradients or artificial depth in favor of structural grids, wireframe geometry, and functional contrast.

## Colors
The palette is grounded in print and terminal metaphors:
- **Primary Ink (`#121212`)**: Serves as the bedrock for all heavy outlines, bold typography, hard shadows, and high-priority solid fills.
- **Canvas Neutral (`#f7f6f0`)**: An archival warm parchment background that prevents the harsh glare of stark white while grounding technical widgets.
- **Card White (`#ffffff`)**: Used for distinct foreground containers and panels to establish direct visual contrast against the canvas.
- **Functional Accents**:
  - `retro-yellow` (`#f6e05e`): High-priority action buttons, interactive hovers, and focal tag badges.
  - `retro-mint` (`#a7f3d0`): System status, live telemetry, and active status chips.
  - `retro-orange` (`#ff8c42`): Secondary technical alerts, specialized service verticals, and highlights.
  - `retro-muted` (`#555555`): Secondary descriptive text and structural subheads.

## Typography
Typographic rhythm balances structural clarity with machine-like precision:
- **Headlines (`Plus Jakarta Sans`)**: Dense, heavy weight (`800`), tightly tracked for strong architectural presence. Large hero displays scale down to a responsive size on mobile screens to preserve line density.
- **Body (`Plus Jakarta Sans`)**: Neutral, highly legible humanist sans-serif set in regular weight (`400`) to balance out the rigid borders.
- **Monospace & Metadata (`Space Mono`)**: Dedicated to navigation items, technical badges, system meters, frame labels, and code metrics. Always rendered with bold weight (`700`) and slight letter spacing for a punchcard-style readout.

## Layout & Spacing
The layout adheres to a fixed-max-width grid (max 1280px / `max-w-7xl`) centered with responsive outer margins (16px on mobile, 32px on desktop). 

Content partitions rely on explicit 12-column subgrids (e.g. 7-column narrative / 5-column visualization in hero areas, and 4-column cards for service and technology matrices). Grid backgrounds use a 24px × 24px subtle coordinate overlay (`grid-paper`). Section dividers consistently use full-width 2px solid `#121212` border rules rather than whitespace separations alone.

## Elevation & Depth
Depth is created entirely through hard, flat offset shadows and high-contrast bounding lines. Soft ambient blur shadows are strictly disallowed.

Key elevation levels:
- **Ground (`elevation-0`)**: Flat on canvas or card surface; bounded by `2px solid #121212`.
- **Raised Sm (`retro-shadow-sm`)**: `box-shadow: 2px 2px 0 #121212`. Used on status indicators, language selectors, tags, and small toolbars.
- **Raised Default (`retro-shadow`)**: `box-shadow: 4px 4px 0 #121212`. Standard for cards, action buttons, and input modules.
- **Raised Lg (`retro-shadow-lg`)**: `box-shadow: 6px 6px 0 #121212`. Reserved for hero viewports, featured case studies, and primary modal containers.
- **Pressed / Active State**: On interaction (`active:` or `hover:` depending on element), elements translate down and right by `+2px +2px` while their shadow shrinks proportionally, mimicking physical microswitch switches.

## Shapes
The shape language is strictly **Sharp (`0`)**. 
- Border radii on cards, buttons, badges, inputs, and viewports are explicitly `0px`.
- Rounded geometric corners are exclusively reserved for functional UI metaphors, such as the 10px circular status dot (`rounded-full`) indicating live availability. All structural elements maintain hard, 90-degree right angles.

## Components

### Buttons
- **Primary**: Solid `retro-yellow` (`#f6e05e`) background, 2px `#121212` border, `retro-shadow` (4px 4px), uppercase or bold `Space Mono` typography. Hover shifts by `+2px, +2px` with shadow reduced to 2px.
- **Secondary / Neutral**: Pure white (`#ffffff`) or parchment background, 2px border, hard shadow. Hover triggers subtle shift and background color shifts.
- **Icon / Control Buttons**: Square aspect ratio (32px × 32px), 2px solid outline, `retro-shadow-sm`.

### Chips & Badges
- Constructed with `Space Mono`, size 10px–11px, bold, with 1px or 2px black outlines.
- Variants utilize high-saturation accent fills (`retro-yellow`, `retro-mint`, `retro-orange`) or inverted black backgrounds with white lettering (`bg-retro-ink text-retro-bg`).

### Cards & Panels
- Framed in 2px solid `#121212` with 4px or 6px hard drop shadows.
- Distinct header bars featuring terminal-style metadata strips (e.g., `[01 / FRONTEND]` or status flags) separated by 2px horizontal hairline dividers.

### Form Inputs
- Background: `#f7f6f0` transitioning to pure white upon `:focus`.
- Outlines: 2px solid `#121212` with sharp corners. Placeholders set in muted gray (`#a3a3a3`).
- Service selectors function as segmented button matrices styled like tactile stamp buttons.

### Visual Containers & Wireframe Viewports
- Outer white wrapper framed with header telemetries (FPS readout, coordinate display, status indicators).
- Inner viewport framed by dark 2px borders, containing canvas graphics rendered in raw geometric vectors.

    // 1. Motor Wireframe 3D en Canvas (Estilo Vector Retro 90s)
    (function init3DViewport() {
      const canvas = document.getElementById('polyhedron-canvas');
      if (!canvas) return;
      const ctx = canvas.getContext('2d');
      const rotLabel = document.getElementById('poly-rot-label');
      const fpsLabel = document.getElementById('viewport-fps');
      const wrapper = document.getElementById('canvas-3d-wrapper');

      // Vértices del icosaedro regular
      const phi = (1 + Math.sqrt(5)) / 2;
      const rawVertices = [
        [-1,  phi, 0], [ 1,  phi, 0], [-1, -phi, 0], [ 1, -phi, 0],
        [ 0, -1,  phi], [ 0,  1,  phi], [ 0, -1, -phi], [ 0,  1, -phi],
        [ phi, 0, -1], [ phi, 0,  1], [-phi, 0, -1], [-phi, 0,  1]
      ];

      const vertices = rawVertices.map(v => {
        const d = Math.sqrt(v[0]*v[0] + v[1]*v[1] + v[2]*v[2]);
        return [v[0]/d, v[1]/d, v[2]/d];
      });

      const edges = [
        [0, 11], [0, 5], [0, 1], [0, 7], [0, 10],
        [1, 5], [1, 9], [1, 8], [1, 7],
        [2, 11], [2, 4], [2, 3], [2, 6], [2, 10],
        [3, 4], [3, 9], [3, 8], [3, 6],
        [4, 11], [4, 5], [4, 9],
        [5, 11], [5, 9],
        [6, 10], [6, 7], [6, 8],
        [7, 10], [7, 8],
        [8, 9],
        [10, 11]
      ];

      let angleX = 0.45;
      let angleY = 0.65;
      let targetRotSpeedX = 0.003;
      let targetRotSpeedY = 0.006;
      let isDragging = false;
      let lastMouseX = 0;
      let lastMouseY = 0;

      wrapper.addEventListener('mousedown', (e) => {
        isDragging = true;
        lastMouseX = e.clientX;
        lastMouseY = e.clientY;
      });

      window.addEventListener('mouseup', () => {
        isDragging = false;
      });

      window.addEventListener('mousemove', (e) => {
        if (!isDragging) return;
        const dx = e.clientX - lastMouseX;
        const dy = e.clientY - lastMouseY;
        angleY += dx * 0.008;
        angleX += dy * 0.008;
        lastMouseX = e.clientX;
        lastMouseY = e.clientY;
      });

      let lastFrameTime = performance.now();
      let frameCount = 0;
      let fpsTimer = 0;

      function render(now) {
        const dt = now - lastFrameTime;
        lastFrameTime = now;

        frameCount++;
        fpsTimer += dt;
        if (fpsTimer >= 1000) {
          if (fpsLabel) fpsLabel.textContent = frameCount + ' FPS';
          frameCount = 0;
          fpsTimer = 0;
        }

        if (!isDragging) {
          angleY += targetRotSpeedY;
          angleX += targetRotSpeedX;
        }

        if (rotLabel) {
          const deg = Math.round(((angleY % (Math.PI * 2)) * 180 / Math.PI));
          rotLabel.textContent = `ROT_Y: ${(deg < 0 ? deg + 360 : deg)}°`;
        }

        ctx.clearRect(0, 0, canvas.width, canvas.height);

        const cx = canvas.width / 2;
        const cy = canvas.height / 2;
        const scale = 140;

        const cosY = Math.cos(angleY);
        const sinY = Math.sin(angleY);
        const cosX = Math.cos(angleX);
        const sinX = Math.sin(angleX);

        const projected = vertices.map(v => {
          const x1 = v[0] * cosY + v[2] * sinY;
          const y1 = v[1];
          const z1 = -v[0] * sinY + v[2] * cosY;

          const x2 = x1;
          const y2 = y1 * cosX - z1 * sinX;
          const z2 = y1 * sinX + z1 * cosX;

          const fov = 3.2;
          const pZ = z2 + fov;
          const projX = cx + (x2 / pZ) * scale * 2.8;
          const projY = cy + (y2 / pZ) * scale * 2.8;

          return { x: projX, y: projY, z: z2 };
        });

        // Aristas estilo trazo retro de tinta
        edges.forEach(edge => {
          const p1 = projected[edge[0]];
          const p2 = projected[edge[1]];
          const avgZ = (p1.z + p2.z) / 2;
          const isFront = avgZ > 0;

          ctx.beginPath();
          ctx.moveTo(p1.x, p1.y);
          ctx.lineTo(p2.x, p2.y);
          ctx.strokeStyle = isFront ? '#121212' : '#888888';
          ctx.lineWidth = isFront ? 1.8 : 1.0;
          ctx.stroke();
        });

        // Vértices retro cuadrados
        projected.forEach((p) => {
          const isFront = p.z > 0;
          const size = isFront ? 6 : 4;
          ctx.fillStyle = isFront ? '#121212' : '#ffffff';
          ctx.strokeStyle = '#121212';
