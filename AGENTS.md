# Repositorio

Este repositorio contiene dos aplicaciones Next.js independientes:

- **`mayderc/`** — portafolio personal. Instrucciones en `mayderc/AGENTS.md`.
- **`danvrix/`** — sitio comercial de Danvrix.dev. Instrucciones en `danvrix/AGENTS.md`.

Cada carpeta tiene su propio `package.json`, `tsconfig.json` y configuración de deploy. No hay un proyecto Next.js en la raíz.
